# Callside website

One-page website for Callside, sales team training on live calls. Plain HTML, CSS and JavaScript in a single file, with no build step and no dependencies.

## Files

- `index.html`: the whole page (markup, styles and script)
- `assets/`: 13 photos (JPEG)

Fonts (Instrument Sans and Inter) load from Google Fonts.

## Publish with GitHub Pages

1. Upload `index.html` and the `assets` folder to the root of the repository.
2. In the repository, open Settings, then Pages.
3. Under "Build and deployment", choose "Deploy from a branch", pick the `main` branch and the `/ (root)` folder, and save.
4. The site appears at `https://<your-username>.github.io/<repository-name>/` after a minute or two.
